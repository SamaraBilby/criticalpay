# CriticalPay

CriticalPay is a high-reliability payment gateway built with Java and Spring Boot.

The project is designed as a hands-on study of software architecture, distributed systems, payment reliability, event-driven communication, SQL/NoSQL persistence, observability, resilience, and cloud-native practices.

## Goals

- Model a reliable payment lifecycle
- Apply Clean Code and SOLID principles
- Use Domain-Driven Design where it adds value
- Evolve from a modular monolith toward distributed architecture only when justified
- Practice idempotency, concurrency control, resilience, and observability
- Build a project suitable for technical interview discussion

## Current stage
